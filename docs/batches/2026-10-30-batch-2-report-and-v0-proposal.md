## (B) v0 proposal

1. **One outcome.** At horizon T the group's state is a partition of its n members into blocks plus a set of leavers: *holds* = one block, no leavers; *splits* = two or more blocks; *who leaves* = the leaver set and the block each member lands in. Aldred picks the instrument per size from A6; v0 is written against the partition, not against any one instrument.
2. **Three sizes.** n = 3 (triad), n = 8–12 (team), n ≥ 100 (crowd); the same equations, with n entering only through the composition operators (091), fitted at one size and tested at the other two.
3. **Fewest drives the evidence forces: three, all `read`.** (D1) **Set point**: pull toward one's own baseline — Gottman uninfluenced steady state a/(1−r) (L3919), FJ anchor (L3994), Wankhede stubbornness w_i (L3993), Altafini decay (L3856), Kuran integrity (L3958). (D2) **Affiliation**: pull toward others' state, gated — Leonard K1 (L3865), Gottman O-jive with dead zone and threshold (L0857, L3921), Kuran reputational utility (L3957), Granovetter threshold as net cost–benefit (L3959). (D3) **Goal**: attraction to a preferred option with strength ω — Leonard sin(θ̂ − θ) (L3864), Couzin intransigence (L3866). Not forced: a triad-consistency drive (L3796 `sa`), status, threat (threat enters only as the cost inside D2's threshold, 089). This is not the seven-drive basis of 050; v0 must say so and say why.
4. **State carried.** Person i: a scalar state x_i (opinion, heading or affect, one per instrument), set point p_i, goal g_i with strength ω_i, gate thresholds K−, K+, inertia r_i. Relation (i, j): a signed weight a_ij; its sign (affiliation vs rivalry) is an **input** — no source derives it (L3857 `sa`). Group: the partition, the signed matrix X, and the threshold distribution F, which is a group-level object no mean reduces to (L1225 read).
5. **Coupling law candidates.** Dyad: W_{t+1} = a + r1·W_t + I_HW(H_t), I an O-jive (L0853, L0857 read; TAR special case L1793 `sa`). Triad: relation layer dX/dt = X² with factions = sign of ω_1 (L0898, L3154 read), constrained statically by the product rule (ledger `sa` only, L2283; 084 read but unwritten). Team: Leonard's slow manifold with θ_c = 2·arccos r (L3874 read) for choose-vs-compromise, and the contraction certificate w_i > Σ_enemies 2|a_ik| (L4004 read) as the no-split condition. Crowd: r(t+1) = F[r(t)] (L3960 read) with Kuran's derived threshold x(S^e) (L3968 read). Across sizes: the certificate ρ(Γ) < 1 (L3996 read), which composes without reciprocity. **Composition gap (083) v0 must fill or declare:** a merge/split law for drive *state* (how a group's state divides among fragments, and when) — declare it: v0 takes the partition from the relation layer (X² sign pattern; clusters at distance ≥ 1) and asserts no state-merge law.
6. **Refutation per size.** n = 3: in longitudinal signed triads, the one-negative triangle must be under-represented and must convert to balanced faster than the all-negative triangle; if conversion runs at the sign-shuffled null rate, the triad law is refuted. Team: a group with κ(G) ≥ 2 and every w_i > Σ 2|a_ik| must split less often than groups failing the condition; if it splits at the same rate, the certificate is refuted; if D2 adds no predictive gain over D1 for who leaves (Madhyastha's dyad finding at team scale), the coupling term goes. Crowd: if raising beliefs about others' turnout *lowers* participation (Cantoni: substitutes), monotone F is refuted; if mobilisation shows no two-level structure where F has three crossings, the threshold map is refuted.
7. **What would be written.** `models/00-v0.md`: definitions and equations only; every term credited by ledger id with provenance; the three refutation tests; the declared composition gap; no code. Terms resting on `sa` lines are marked inadmissible in the text itself.
