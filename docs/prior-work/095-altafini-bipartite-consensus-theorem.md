## 1. Citation and vocabulary

Altafini, C. (2013). Consensus problems on networks with antagonistic interactions. *IEEE Trans. Autom. Control* 58(4): 935-946. doi:10.1109/TAC.2012.2224251.

**Their vocabulary.** Signed graph, antagonistic interaction, structural balance, **bipartite consensus** ("agreed upon dissensus"), gauge transformation (orthant change), agreement subspace, Laplacian potential, monotone system. Application language (introduction): "two-party political systems, duopolistic markets, rival business cartels, competing international alliances (think of the Iron curtain era)" [read]; a positive or negative weight is "friend/foe (allied/adversary)", "trust/distrust, like/dislike" [read].

**Drives/operands.** None in the drive sense. Operands are scalar real states `x_i` per agent ("opinions" in the introduction's gloss); the only structure is the signed adjacency `A`. No agent-level motive exists in the model; sign of `a_ij` is an exogenous, fixed label of a dyad. Interaction rule is fixed by the Laplacian, not chosen by the agent.

## 2. Definitions, exactly [read, manuscript]

- Signed graph `G = {V, E, A}`, `A in R^{n x n}`, `a_ij != 0 <=> (v_j, v_i) in E`; no self-loops. **Digon sign-symmetry**: `a_ij a_ji >= 0` (paired directed edges never have opposite signs).
- Cycle (semicycle for digraphs) is **positive** if it has an even number of negative weights (`a_{i1 i2} ... a_{ip i1} > 0`), negative otherwise.
- Connectivity: "Irreducibility of A corresponds to G(A) which is strongly connected ... (strong connectivity collapses into connectivity when A is symmetric)."
- **Weight balanced** (the "balanced" of the consensus literature, NOT Heider balance): `C_r = C_c`, where `C_r` is the diagonal matrix of `sum_j |a_ij|` (row) and `C_c` the column analogue. For nonnegative weights `A1 = A^T 1`.
- Dynamics (2): `x' = u`. Signed Laplacian `L = C - A` **with absolute values in the diagonal** (`l_ii = sum_{j in adj(i)} |a_ij|`, `l_ik = -a_ik`). Footnote: the version without absolute values has 0 as eigenvalue always but can have negative eigenvalues, "rendering the Laplacian useless for convergence purposes."
- Laplacian potential (3): `Phi(x) = x^T L x = sum |a_ij| (x_i - sgn(a_ij) x_j)^2`, "The effect of a negative weight a_ij is to replace the usual (x_i - x_j)^2 term ... with (x_i + x_j)^2."
- Protocol (4): `x' = -L x`, componentwise `x_i' = - sum_{j in adj(i)} |a_ij| (x_i - sgn(a_ij) x_j)`.
- **Definition 1.** (4) "admits a bipartite consensus solution if `lim |x_i(t)| = alpha > 0` for all i."
- **Definition 2.** `G(A)` is structurally balanced if there is a bipartition `V1, V2` with `a_ij >= 0` within each part and `a_ij <= 0` across. Unbalanced otherwise. Nonnegative graphs are the special case with one part empty.
- Gauge transformation: `D = diag(sigma)`, `sigma_i in {+1,-1}`, `z = D x`, `L_D = D L D = C - D A D`. **Proposition 2**: `L` and `L_D` are isospectral; the class has at most `2^(n-1)` distinct matrices.

## 3. Theorems, exactly [read, manuscript numbering]

**Lemma 1** (undirected): "A *connected* signed graph G(A) is structurally balanced if and only if any of the following equivalent conditions holds: 1) all cycles are positive; 2) there exists `D` with `DAD` entrywise nonnegative; 3) 0 is an eigenvalue of `L`." Condition 1 attributed to Cartwright-Harary [12]; footnote 3 says it "is often taken as definition of structural balance".

**Corollary 2**: a connected signed graph is unbalanced iff one or more cycles are negative / no such `D` / `lambda_1(L) > 0` (i.e., `Phi(x) > 0`).

**Theorem 1** (restated, not quoted in full): for a **connected** signed graph G(A), system (4) "admits a bipartite consensus solution if and only if G(A) is structurally balanced" (Altafini). If `D` is the gauge transformation that renders `DAD` nonnegative, the limit is `lim x(t) = (1/n) 1^T D x(0) D 1`; if G(A) is structurally unbalanced, `lim x(t) = 0` for all `x(0)`. Proof: balanced case reduces to average consensus on a nonnegative connected undirected graph via `z = Dx`; unbalanced case: `Phi` is positive definite.

**Lemma 2** (digraph): "A **strongly connected, digon sign-symmetric** signed digraph is structurally balanced iff: 1) `G(A_u)` balanced (`A_u = (A + A^T)/2`); 2) all directed cycles positive; 3) some `D` makes `DAD` nonnegative; 4) 0 is an eigenvalue of `L`." **Corollary 3** gives the unbalanced equivalents, including `-L` Hurwitz. **Proposition 1** (proved in appendix): for strongly connected, digon sign-symmetric digraphs, no negative semicycle iff no negative directed cycle.

**Theorem 2** (digraph, linear; restated): for a **strongly connected, digon sign-symmetric** signed digraph G(A), system (4) admits a bipartite consensus solution iff G(A) is structurally balanced. In that case `lim x(t) = nu^T D x(0) D 1` (`nu` the normalised left null vector of `DLD`, `nu^T 1 = 1`); when G(A) is weight balanced the limit is `(1/n) 1^T D x(0) D 1`; if G(A) is structurally unbalanced, `lim x(t) = 0` for all `x(0)`. Unnumbered paragraph after the proof of Cor. 3 (not a numbered Remark; corrected in validation): "any acyclic digraph is structurally balanced, hence these cases can be treated analogously to their nonnegative weight counterparts (i.e., rooted trees admit a bipartite consensus [40])". Sec IV-A adds that the nonlinear arguments "can be extended to the case of G(A) with a rooted tree (following the lines of e.g. [34])". Both are asserted by analogy and citation; the manuscript gives no theorem or proof for the rooted-tree/non-strongly-connected case.

**Proposition 3** (diagonal stability): strongly connected, digon sign-symmetric, **weight balanced**: `-L` is diagonally stable (Lyapunov function `V = ||x||^2`, Remark 2: `V' = x^T L_hat_u x < 0`) iff unbalanced.

**Switching** (sec III-B.2): `r` topologies, each digon sign-symmetric and **strongly connected**, with non-conflicting signs `sgn(A_p,ij) sgn(A_q,ij) >= 0` for all `p, q, i, j` (eq. 14). Then all can be gauge-made nonnegative by the same `D`, and "Thm 9 of [38] (Olfati-Saber & Murray) holds for the family and assures convergence to `(1/n) 1^T D x(0) D 1` for any switching pattern." Remark 3: cannot be relaxed to gauge-equivalent digraphs violating (14). Remark 4: strongly connected but unbalanced topologies obeying (14) give a Hurwitz polytope with common Lyapunov function `||x||^2`.

**Theorem 3** (nonlinear, sec IV): strongly connected, digon sign-symmetric, **weight balanced**; protocol (21) with `h in S`: bipartite consensus iff balanced. **Theorem 4**: same hypotheses, antisymmetric-function family. **Theorem 5**: "Any distributed strongly monotone system (16) whose Jacobian is globally epsilon-strongly connected admits a Laplacian flow (28) globally converging to a bipartite consensus." (monotone-systems construction; not read beyond statement and the proof outline).

**Numerical illustrations [read]**: Example 1 `A1 = [[0,1,-2],[1,0,-4],[-2,-4,0]]`, balanced, `sp(L1) = {0, 4.35, 9.65}`; Example 2 `A2 = [[0,1,-2],[1,0,4],[-2,4,0]]`, unbalanced, `sp(L2) = {1.2, 2.61, 10.18}`; Example 4: `n = 1000` strongly connected balanced digraph gives bipartite consensus; "As soon as the sign is changed even on a single edge ... structural balance is lost ... `x(t) -> 0`, although the convergence rate can be very slow." These are simulations, not data.

## 4. The connectivity hypothesis, settled

| Setting in the manuscript | Hypothesis | Conclusion |
|---|---|---|
| Undirected, linear (Thm 1) | **connected** (symmetric `A`) | bipartite consensus iff balanced; **else every state to 0** |
| Directed, linear (Thm 2) | **strongly connected + digon sign-symmetric** | same; else to 0 |
| Directed, switching | each topology strongly connected, digon sign-symmetric, non-conflicting signs (14); proof cites OSM Thm 9 (which needs weight balance) | convergence to the bipartite point |
| Nonlinear (Thm 3-4) | strongly connected + digon sign-symmetric + **weight balanced** | iff balanced |
| Rooted tree / acyclic | stated as a remark only | bipartite consensus (balanced automatically) |
| Non-strongly-connected, unbalanced | **not covered by any theorem** | not stated |

So the correct compressed statement is: **"for a strongly connected (undirected: connected), digon sign-symmetric signed graph, the Laplacian flow `x' = -(C - A)x` has a nonzero limit iff the graph is structurally balanced, and otherwise converges to the origin for every initial state."** The standard account's "iff balanced, else zero" omits the hypothesis; it is false without it.

**Proskurnikov-Matveev-Cao Theorem 1 [read] (static, general directed graph):** "Let `A(t) = const`. The protocol (4) is *stabilizing* iff the graph is neither SB itself nor contains an **in-isolated structurally balanced (ISB) subgraph**. Bipartite consensus is established iff `G[A]` is structurally balanced and quasi-strongly connected (QSC): if `a_jk >= 0` for all `j, k`, consensus; otherwise opinions polarize." **Example 1 [read]**: three agents, `a12 = a21 = -1`, `a31 a32 > 0`, i.e. 1 and 2 are mutual antagonists who ignore agent 3, and 3 follows both: not strongly connected, unbalanced, yet `x' = (-x2 - x1, -x1 - x2, a31 x1 + a32 x2 - (|a31|+|a32|) x3)` has an equilibrium line `(xi, -xi, rho xi)`, `rho = (a31 - a32)/(|a31|+|a32|) in (-1,1)`. The limit is neither polarisation (bipartite) nor zero. Proskurnikov's Fig. 1 labels this graph **QSC** (agent 1 or 2 is a root), so quasi-strong connectivity is not enough; strong connectivity, or the absence of ISB subgraphs, is what Altafini's zero limit needs [read]. The limit is reached: `x1 - x2` is conserved and `x1 + x2 -> 0`, so the state goes to the line with `xi = (x1(0) - x2(0))/2` (my arithmetic from their equations). This is the counterexample to "unbalanced implies zero" without strong connectivity.

## 6. What changes with group size and composition

- **Size.** The results are exact for any finite `n`; nothing depends on `n` in the statement. What depends on `n`: the gauge class has up to `2^(n-1)` members (Prop. 2); of the `2^m` sign assignments on `m` edges of a connected graph, exactly one gauge class is balanced and `2^(m-n+1) - 1` are unbalanced (sec III-A.3), so **a random sign pattern is balanced with probability `2^(-(m-n+1))`, vanishing quickly as the graph gets more cyclic** (the class counts are Altafini's [read]; the probability is my arithmetic from them, `2^(n-1)/2^m`). Convergence time can be "very slow" for large `n` in the unbalanced case (Example 4, n = 1000, simulation only; no rate bound stated in the manuscript). Balance checking is polynomial time.
- **Composition.** Everything hinges on the sign pattern and connectivity: one flipped edge on a balanced strongly connected graph can turn bipartite consensus into collapse to 0 (Example 4 text: "even on a single edge"; its Fig. 3(b) caption says "a few edges have changed sign"; a single flip unbalances only if the edge lies on a cycle, since flipping a bridge keeps balance); removing the strong connectivity (a subgroup that ignores the rest) breaks the theorem entirely (Proskurnikov Example 1). A group in which any two mutual antagonists are not both listened-to by everyone is outside the theorem. The merge of two balanced strongly connected groups is not treated (083 sec 2.1 asks that).
- **Intervention.** None: the model is descriptive of a fixed protocol; there is no consent/manipulation question. The "design" language (Laplacian feedback design for engineered agents) is control of agents' protocol, which for people would be manipulation of the rule rather than the state.

## 7. Scale of the result

Group (cohesion/split), as a pure mathematical claim about the long-run limit of a continuous-time linear flow. It is membership-free (no join/stay/leave) and crowd-free (no adoption data). The two-faction outcome is the formal analogue of a split of the group at the level of a scalar state.

## 8. Operand/operator translation for the algebra

- **Operand:** a scalar state per person, plus a signed weight per ordered dyad. The signed dyad weight is a natural operand for "ally/adversary" operators; **the sign is fixed and exogenous**, which is a limitation (relations do change; Proskurnikov et al.'s Theorem 2 [read]: bounded gains and a uniformly strongly connected (USC) time-varying graph give modulus consensus, `|x_i|` converging to a common limit).
- **Operator:** the Laplacian `L = C - A`, with the key identity `x_i' = -sum |a_ij| (x_i - sgn(a_ij) x_j)`: attraction toward the neighbour's state if `a_ij > 0`, toward its negation if `a_ij < 0`. In an algebra this makes "antagonism" an operator that **reflects then averages** (state `x_j -> -x_j`, then pull). A gauge transformation `D` is a relabelling operator (flip the sign of a faction) under which the dynamics is conjugate (isospectral); that is a genuine symmetry usable as a quotient.
- **Theorem usable as a derivation rule:** balance ⇔ existence of a gauge `D` making all weights nonnegative ⇔ `0 in spec(L)`. Anything beyond the limit `(1/n) 1^T D x(0) D 1` (e.g. what each person ends at as a function of drives) is not given.
- **Does not supply:** why ties have the sign they do, how signs change, what individuals want. Nothing reads as a drive.

## 9. What exists vs what does not

Exists: exact limit theorems for the linear Laplacian flow on strongly connected, digon sign-symmetric signed graphs (balanced → ± common modulus; unbalanced → 0), nonlinear and switching extensions with extra hypotheses, a clean conjugacy (gauge) structure, a Hurwitz/Lyapunov characterisation (`||x||^2`, weight-balanced case), and a counterexample class (in-isolated balanced subgraphs) outside the hypothesis.
Does not exist (in what I read): any fit of `A` or the dynamics to human data; any account of how signs arise or flip; any size-dependent convergence rate; any treatment of sign-asymmetric ties; any account of what happens to a group on collapse to 0 other than the mathematical limit.

## Does it reduce to a drive basis?

Largely no, and honestly it never tries. What reduces: nothing as a drive. The state `x_i` is an opinion-like scalar, and the signed weight is a relation. A drive reading is possible only by interpretation: a positive `a_ij` as an attraction toward conformity with `j` and a negative `a_ij` as a pull toward the opposite of `j` (a contrariety or distancing drive), and `|a_ij|` as the strength; the Laplacian is then "sum of dyadic conformity and anti-conformity pulls". That is a drive in the weak sense of a gradient (the flow is gradient descent of `Phi`, which Altafini states: "the gradient system `x' = -Lx`"), but the pulls are specified by the relation, not derived from any need of the person. What does NOT reduce: the sign pattern (who is an ally or foe) is exogenous and decides the whole outcome; structural balance is a property of the graph (cycle parity), not of any individual; the collapse to 0 in unbalanced groups is a collective property of the cycle structure that no single drive predicts. If anything this supports the hypothesis that some group-level outcomes (polarisation vs collapse) are properties of the relational structure, and that drives of persons enter only through what sets the signs and weights.

## What does it predict or control, and how well?

Outcome predicted: the long-run limit of a scalar opinion state under a fixed signed linear protocol: two antagonistic factions at equal modulus (balanced) or zero (unbalanced), under strong connectivity. This is a theorem, so it is exactly right inside its hypotheses and silent outside them (it fails, per Proskurnikov Example 1, as soon as a balanced subgroup is in-isolated). Control: for engineered agents it prescribes the protocol (a design), not a lever on people; no consent/manipulation question arises because no people are involved. Out-of-sample evidence: none in the sources read; every example (n = 3, n = 1000) is simulation of the model itself. No effect sizes exist because nothing is estimated from data. Failures: (i) the zero limit for unbalanced groups is the model's mathematical output and an implausible prediction for real unbalanced groups (real groups do not all go silent), which suggests the model's collapse is an artefact of the fixed-sign, fixed-weight, no-stubbornness assumptions; this is my inference, not a result in the sources; (ii) Altafini's own examples use the "Iron curtain" and cartels as motivation but cite no data. Empirical content about real signed networks sits in 084 (Facchetti et al., Leskovec et al.), not here.
